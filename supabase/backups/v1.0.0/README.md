# Backup lógico v1.0.0

Este diretório identifica o schema estável da Bros Store sem copiar dados pessoais
ou segredos. O conteúdo restaurável está em `supabase/migrations`; o manifesto
`migrations.sha256` detecta qualquer alteração posterior nos arquivos aprovados.

O procedimento completo de validação e restauração está em `docs/PRODUCAO.md`.
